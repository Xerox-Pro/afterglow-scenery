# AFTERGLOW — 風景に、ひたる。

海、海上花火、ビーチ、渋谷をモチーフにした四つの動く風景。

公開先: https://afterglow-scenery.2026-97th.workers.dev/

## 機能

- WebGLの水面シェーダー: 複数の波、反射、空と雲、砂浜、泡、昼・夕暮れ・夜。
- 花火: 打ち上げ、重力と空気抵抗、残光、煙、水面の反射。画面タップでも打ち上げ。
- 渋谷: 3Dの街並み、380人の歩行者、車、信号、動くオリジナル看板。実測地図の完全再現ではありません。
- WebGLが利用できない環境ではCanvas 2Dによる代替描画。
- スマホ操作、ドラッグ視点、没入モード、画質の自動調整、一時停止、環境音。
- 環境音はWeb Audioで合成。マイク・位置情報・ログイン不要。
- 動きを減らすOS設定では一時停止で開始。

## 操作

`1`〜`4`: シーン切替 / `Space`: 再生・一時停止 / `H`: 没入モード / `M`: 環境音 / `F`: 全画面。

## 開発・公開

`dist/` が静的サイト本体。任意のHTTPサーバーで配信できます。

```bash
python3 -m http.server 8080 --directory dist
```

自己完結のCloudflare Workerを生成:

```bash
python3 build.py
npx wrangler deploy
```

外部画像・動画・CDNのJavaScriptに依存しません。Google Fontsが読み込めない場合はシステムフォントにフォールバックします。

## 検証

- JavaScript構文確認。
- EGLによる水面シェーダーのコンパイルと3モードの画像出力。
- 渋谷のシーン生成と時刻別の更新処理、座標が有限値であることを検証。
- ブラウザーでCanvas代替描画、シーン切替、設定、再生・一時停止、没入モードを確認。
- 確認用ブラウザーのWebGLが無効なため、WebGL版のブラウザー内での最終表示は未確認。
